# 2025

## 年终总结
> date: 2026年1月8日

1. **今年什么事做得比较好？**
	1. 看书：下半年看了好几本书
	2. 记录：记录健身、记录想法、记录 Unity 学习
	3. 健身：维度和当时考研练的两个月相当
	4. 努力到细节：
		1. 找实习：简历优化、面经的收集记录复盘、北京的吃苦。
		2. 深圳租房：整日搜集信息，整理需要置办的家具，一件一件的搬上楼、叫货拉拉，闲鱼线下去拆卸、回家安装...
		3. 做毕设，整日钻研，做自己喜欢的Demo。
		4. 入职Demo，努力到最后一刻，细节和美术打磨到位，得了最佳团队奖。
	5. 没有做不必要的省钱：
		1. 租房交通方便，离公司近
		2. 买手办，可以适当重视情绪价值
		3. 单车年卡，每天都能节约几十分钟时间。
		4. 健身月卡，近，正反馈多，既节约了时间还巩固了健身意愿
2. **今年什么事做得不太好？**
	1. 脾气和思想，在亲密关系的处理上没有什么改进
	2. 急躁的心态，在工作和生活中还是很容易急躁，不能静下心慢慢享受、处理事情
	3. 艺术方面没有关心了，不再看电影、不再摄影了，精神食粮应该是必不可少的
	4. 和家人联系很少，并且很烦躁，不能妥善处理家庭关系
3. **我学到了什么？**
	1. 从工作：
		1. 盖瑞：每次都做得比预期的好一点，渐渐做越来越复杂的需求
		2. 云吞：要即使记录，书读百遍、其意自现
		3. 老A、盖瑞：没有必要特意攒钱
		4. 项目：模块化代码、PhotonView断线重连、本地配置代码、接口&继承实现可拓展性、OdinSerializer的方便使用
	2. 从书影音：
		1. 《掌握习惯/原子习惯》：建立各种习惯路径，保持一致，能优化效率，降低每次的抉择时间
		2. 《富爸爸穷爸爸》：让钱为我工作，很多时候不需要钱就能从中产生价值
		3. 明年可以看下道德经
		4. 《焦虑的人》：各家各有各家难，不必焦虑，人人都有自己的特殊需求
		5. 《自控力：和压力做朋友》：学知识、看书最重要的不是概念记得有多么清晰，而是看过作者的观点之后，会一直潜移默化的影响你的思维方式
		6. 《心生之境》：汉庭老板的书，第一章讲了很多数理化与生活哲学之间的联系，与个人思想异曲同工之妙
		7. 《亲密关系》：看一段就收获一段，男女之间的社会氛围差异和少得可怜的社会性差异挺有意思，每次看完之后就会狠狠反思自己，看完之后的一段时间里会主动去维护亲密关系。
	3. 从生活：
		1. 要摸清社会中各种规定的规则、能报销的尽量报销，研究一小会儿，可能会剩下很多税款、不必付出的钱
		2. 伴侣：乐观、不急躁地面对大部分事情
		3. 朋友：有事多咨询专业人士，可能会有不一样的思路
4. **很想做但没完成的事情？**
	1.
